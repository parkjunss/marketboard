# 비용 민감도와 결과 내보내기

## General

저장된 기간 검증 기록의 설정·가격·준비 구간을 재사용해 비용 조건만 바꿨을 때의 결과를 비교한다. 같은 조건에서 다시 계산할 수 있도록 비교 결과를 별도 기록으로 보관한다. 실제 주문·외부 가격 조회는 하지 않는다.

## Function

1. 자동 모의 매매 → 기간 검증에서 저장 기록을 선택한다.
2. 비용 민감도에서 비교 수수료·슬리피지를 입력한다. 원래 비용은 기준 행으로 자동 포함한다.
3. 표와 그래프로 결과를 비교한다.
4. CSV로 수치를 내려받거나 독립 HTML 보고서로 공유·인쇄한다. HTML은 브라우저 인쇄를 통해 PDF로 저장할 수도 있다.

## Spec

- 추가 조건 1~8개, 기준 포함 최대 9개. 각각 0~100bp, 1bp = 0.01%.
- 기준 및 비교 조건 사이의 숫자상 중복을 거부한다. `5`와 `5.0`은 같은 값이다.
- 각 조건은 초기 자금과 보유 수량 0으로 검증 구간을 다시 실행한다. 수수료와 슬리피지만 변경한다.
- 기존 Python `compare_auto` 계산을 사용한다. 비용에 따라 체결 수량·매도 잔량·후속 거래 횟수가 달라질 수 있으므로 비용을 단순 차감해 추정하지 않는다.
- 슬리피지는 체결 가격에 반영되고, 수수료 합계와 별개다. 마지막 종가로 보유분을 평가하며 강제 청산 비용을 가정하지 않는다.
- V45: `auto_trading_cost_analyses`에 소유자·원본 검증 ID·요청 키·추가 조건·모든 결과·생성 시각을 저장한다. 최대 100개/계정.
- 소유권 확인, 사용자 행 잠금, 요청 키 중복 방지, 실패 시 전체 롤백을 적용한다. 원본 검증 기록은 변경하지 않는다.
- 보고서는 저장 결과에서 생성한다. 계산 서버나 최신 시장 가격에 의존하지 않는다.
- CSV: UTF-8 BOM, RFC 4180 인용 및 CRLF, 조건별 성과와 메타데이터. 수식으로 해석될 수 있는 문자열을 방어한다.
- HTML: 외부 스크립트·폰트·이미지 없이 메타데이터·시나리오 그래프·성과 표·일별 자산 표를 포함한다. 사용자 입력을 HTML 이스케이프한다.
- 파일에 계정 정보·로그인 정보는 포함하지 않는다. 전략 이름과 설정은 포함한다.
- 보고서 파일은 브라우저 다운로드로 제공하며, 서버에 공개 URL을 만들지 않는다.

| API | 동작 |
|---|---|
| POST `/api/auto-trading/validations/{id}/cost-analyses` | `scenarios: [{feeBps, slippageBps}]`로 비교, Idempotency-Key 필수 |
| GET `/api/auto-trading/validations/{id}/cost-analyses` | 해당 검증의 비용 비교 목록 |
| GET `/api/auto-trading/cost-analyses/{id}` | 원본 검증 정보와 저장 비교 결과 |
| GET `/api/auto-trading/cost-analyses/{id}/export?format=csv\|html` | 인증 후 filename·contentType·content JSON 반환, 브라우저가 파일로 다운로드 |

수정주가·배당 반영과 거래일 누락 여부는 미확인이다. 조정/검증 날짜 분리는 사용자가 검증 기간을 과거에 보지 않았다는 보장이 아니다. 같은 구간을 반복 확인하며 설정을 바꾸면 조정에 사용한 구간으로 취급해야 한다.
