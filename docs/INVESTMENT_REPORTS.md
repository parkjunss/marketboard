# 종목 투자 보고서 1차

## 사용

로그인 → 종목 상세 → 투자 보고서 보기 → 새 보고서 생성.
`/symbols/{ticker}/reports`에서 최근 50개 이력을 조회하고 `/reports/{id}`에서 저장본을 연다.
인쇄 / PDF 저장 버튼은 브라우저 인쇄 대화상자를 사용한다.

## 저장 계약

- `POST /api/reports`, JSON `{ "ticker": "NVDA" }`, `Idempotency-Key: UUID`.
- `GET /api/reports?ticker=NVDA`, `GET /api/reports/{id}`.
- 인증된 사용자 ID로 소유권을 결정하며 다른 사용자의 보고서는 404.
- V27 `stock_reports`에 시세·일별 종가·재무 캐시·정량 분석·검증 안내와 버전을 JSON 스냅샷으로 저장한다.
- 생성은 기존 행을 수정하지 않는다. 동일 요청 키의 저장은 기존 응답을 반환한다.
- 자료별 조회 실패는 부분 보고서로 표시하고 전부 조회하지 못하면 생성을 거절한다.

## 데이터 범위

가격은 기존 ResolvedPrice의 공급처·관측 시각·상태를 보존한다. 일별 종가는 저장 이력 최대 252개이다.
재무는 yfinance 기반 캐시의 실제 payload와 fetchedAt을 함께 보존한다. 재무 24시간 및 정량 분석 7일 경과 안내는 운영상 경고 기준이며 공시 최신성 인증이 아니다.
정량 분석은 기존 252거래일 요청을 사용한다. 변동성은 EWMA(0.94), 252일 연환산이다. VaR/CVaR는 역사적 일별 손실 백분율이다.
AI, 목표가, 매수 등급, 실적 추정은 포함하지 않는다.

## 한계

자료 취합은 동시 시세 스냅샷이 아니다. 통화, 공시 원문/발표일, 주식분할 조정의 공통 정규화는 미완료이며 화면에 표시한다.
공급처 링크는 현재 웹페이지 링크로, 당시 원문을 보존한 인용이 아니다. 저장본은 조회할 때 갱신되지 않는다.
HTML 파일 다운로드는 제공하지 않으며 브라우저 인쇄/PDF 저장을 지원한다.

## 배포

프론트엔드와 백엔드를 함께 배포하고, 백엔드 시작 시 Flyway V27을 적용해야 한다.
운영 DB와 운영 사이트 반영 여부는 로컬 빌드 및 H2 테스트와 별도로 확인해야 한다.

## 검증 기록

- Next.js production build, TypeScript 검사 및 변경 화면/API ESLint 통과.
- 보고서 서비스/H2 영속성 테스트: 부분 자료 및 오래된 가격 안내, 빈 보고서 거절, JSON 복원, 소유권 제한, 이전 버전 유지, 중복 저장 방지 확인.
- 실제 MySQL V27 적용, 로그인 브라우저에서 실제 데이터 생성, 인쇄 레이아웃은 미검증. 확인 당시 로컬 서비스와 Docker 엔진이 실행되지 않았다.
