# 포트폴리오 설계 — Function

## 기간 분리 검증

사용자는 산출 기간과 그 이후 검증 기간을 직접 입력하거나 `1년 산출 + 이후 3개월 자동 설정`을 선택한다. 산출 비중을 유지한 매수 후 보유 성과를 동일 비중·SPY와 비교하고, 초기 자금·현금·실제 관측 기간·최대 낙폭·회복 기간을 확인한다. 검증 데이터가 부족해도 산출 결과를 보존하고 종목별 부족 사유를 표시한다. 검증 결과를 본 뒤 조합을 재선택하는 행위는 독립적인 성과 검증과 구분한다.

상태: 설계 초안. [목적](Portfolio_Lab_General.md) / [계산·검증](Portfolio_Lab_Spec.md)

## 첫 화면: 조건

- 투자 가능 금액(USD), 남길 현금 금액.
- 후보는 SPY·QQQ·EFA·EEM·IEF·GLD 6종을 기본 선택하며, 주식·ETF를 직접 검색·추가·제외할 수 있다. 분석 시작·종료일을 지정한다.
- 자산별 최대 비중, 무위험 수익률 가정. 기본은 공매도·차입 없음.
- 목표는 최소 변동성 또는 위험 한도 내 수익 추정치 최대화. 목표를 달성할 수 없는 조건은 이유를 표시한다.

## 계산 결과

1. 데이터 상태: 실제 사용 기간, 공통 수익률 관측 수, 종목별 누락·최신성·사용 가능 여부.
2. 자산 비교 표: 과거 누적 수익률, 연환산 평균 수익률, 연환산 변동성, 최대 낙폭. 각 수치의 기준 기간 명시.
3. 위험–수익 차트: X축 연환산 변동성, Y축 과거 자료 기반 연환산 평균 수익률. 개별 자산, 동일 비중, 최소 분산, 제약 효율적 투자선 표시.
4. 차트의 포트폴리오 선택 또는 키보드로 같은 후보 선택 → 배분 표 갱신. 위험 한도 입력과 선택 후보는 구분한다.
5. 배분 표: 종목, 전체 자금 기준 비중, 배분 금액, 수량 산정용 가격·가격일, 참고 수량, 남는 현금. 현금도 한 행으로 표시한다.

## 후속 화면

월말 ETF 모멘텀은 고정 규칙 전략으로 비교한다. 분석 결과 저장과 모의 운용을 첫 계산의 선행 조건으로 요구하지 않는다. 기존 보유와의 리밸런싱 비교는 초기 신규 자금 배분 흐름이 검증된 뒤 연결한다.

## 부분 성공

한 종목이 부족하다고 모든 지표를 지우지 않는다. 계산 가능한 개별 지표는 유지한다. 후보를 자동으로 제외하거나 동일 비중으로 몰래 대체하지 않는다. 부족 종목을 사용자가 제외한 후 다시 계산할 수 있게 한다. 조건 변경 후 이전 결과는 이전 조건의 결과라고 표시하거나 무효화한다.
