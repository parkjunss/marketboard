# 손실 축소·판단 참고 신호 프로토콜 (v1)

작성일: 2026-10-29 · 상태: 평가 전 고정 · 브랜치: `feat/factor-ranking`

## 목적

수익률을 더 내는 신호가 아니라 **손실 위험이 큰 시기를 알려주고 노출을 줄이는 신호**를 검증한다. 수익률과 달리 변동성은 군집하는 성질이 있어 예측 가능성이 높다. 통과한 규칙은 앱에서 "정상 / 주의 / 위험" 참고 상태로 보여주며, 자동 주문하지 않는다.

## 이미 본 결과 (편향 기록)

- 팩터 평가에서 횡단면 `trend_200`, `low_vol_60`의 결과를 이미 봤다. 이번 질문(같은 자산의 시계열 위험·낙폭)과 다르지만 완전한 백지 상태의 설계는 아니다.
- RL 위험 오버레이(노출 상한 25%, 변동성 목표 10%)가 SPY 검증에서 낙폭을 줄인 결과를 봤다. 이번에는 RL 없이 단순 규칙만 평가한다. 단순 규칙이 통과하면, RL은 이후 이 규칙을 이겨야 하는 비교 대상이 된다.

## 데이터와 구간

- ETF 스냅샷 `artifacts/factor-research/etf-snapshot-2026-10-29`의 15개 ETF(U1 섹터 9 + U2 멀티자산 6). 자산마다 독립된 시계열로 평가한다.
- 일봉 252개 이상 쌓인 날부터 사용한다. 구간은 팩터 계획과 같다: 개발 ~2014-12, 검증 2015-01~2019-12, 보류 2020-01~. **보류 구간은 규칙 하나를 고른 뒤 한 번만 연다.**
- t일 종가로 신호를 계산하고 t+1일 시가에 비중을 바꾼다. 수익은 시가→다음 시가 조정 수익률로 계산한다. 비중을 바꿀 때마다 편도 10bps × |Δ비중| 비용을 뺀다.

## A. 예측력 측정 (위험 점수가 미래 위험을 아는가)

점수(t일 종가까지의 정보만 사용):
- `vol_20`: 20일 실현 변동성(연환산)
- `below_200`: −(종가 / 200일 평균 − 1). 높을수록 추세 아래
- `drawdown_252`: 252일 고점 대비 하락률

대상(t+1~t+21 거래일):
- 미래 21일 실현 변동성
- 미래 21일 최대낙폭

측정: 자산별 Spearman 상관. 21거래일 간격으로 겹치지 않게 표본을 뽑고, 15개 자산의 중앙값과 양수 자산 수를 센다.

## B. 노출 규칙 (사전 지정 4개)

| ID | 규칙 | 비중 |
| --- | --- | --- |
| R1 추세 | 종가 < 200일 평균이면 현금 | 0 또는 1 |
| R2 변동성 목표 | 연 15% 목표 | min(1, 0.15 / vol_20) |
| R3 추세+변동성 | R1 × R2 | 0~1 |
| R4 추세 여유 | 200일 평균 아래 2%를 넘으면 현금, 위 2%를 넘으면 복귀(그 사이는 직전 상태 유지) | 0 또는 1 |

비교 기준: 같은 자산의 매수 후 보유(비중 1).

지표: 최대낙폭, 연환산 수익률, 샤프(무위험 0), 연 회전율, 평균 비중.

## 통과 기준 (개발·검증 구간 각각)

1. 15개 중 12개 이상 자산에서 최대낙폭 < 매수 후 보유
2. 최대낙폭 상대 감소율의 중앙값 ≥ 20%
3. 샤프 차이의 중앙값 ≥ −0.05 (위험 대비 성과가 의미 있게 나빠지지 않음)

선택: 개발·검증을 모두 통과한 규칙 중에서 검증 구간 샤프 차이 중앙값이 가장 큰 것. 동률이면 회전율이 낮고 단순한 것을 고른다. 선택한 1개만 보류 구간에서 같은 기준으로 확인한다.

## 추가: 보류 구간 예측력 확인 (2026-10-29, 보류 구간을 열기 전에 고정)

개발·검증 결과(A)를 본 뒤 추가한 확인 단계다. 보류 구간(2020-01 ~ 미래 21일이 확보된 마지막 신호일)에서 **예측력(A)만** 측정한다. 노출 규칙(B)은 선택된 규칙이 없으므로 보류 구간에서 평가하지 않는다.

- 1차 기준(판정): `vol_20` → 미래 21일 변동성. 15개 ETF의 Spearman 중앙값 > 0이고, 12개 이상 자산에서 양수.
- 2차 기준(판정): `vol_20` → 미래 21일 최대낙폭. 기준은 1차와 같다.
- 나머지 점수(`drawdown_252`, `below_200`)는 서술 통계로만 보고한다.
- 표본 추출 방법(21거래일 간격, 겹치지 않음)과 점수 정의는 A와 같다.
- 이 확인을 마치면 2020년 이후 가격은 "이미 본 데이터"가 된다. 이후 이 구간에서 하는 노출 규칙 평가는 사전에 보지 않은 데이터에 대한 독립 검증이라고 부르지 않는다.

## 이후 (통과 시)

- 참고 상태 정의: 선택한 규칙의 비중 1 = 정상, 0 < 비중 < 1 = 주의, 0 = 위험. 각 상태 근거(추세 거리, 변동성)를 함께 표시한다.
- 앱 연동(collector 계산 → 화면 표시 → 주간 점검 알림)은 결과를 보고한 뒤 따로 확인받고 진행한다.
