# 이동평균 원장과 단일 쓰기 경로를 채택한다

포트폴리오 거래 원장은 이동평균법으로 원가를 계산한다. 매수 수수료는 취득원가에 포함하고 매도 수수료는 매도대금에서 차감하며, 이는 투자점검용 계산이지 세무 신고용 계산이 아니다. FIFO는 로트 추적과 이관 복잡도가 현재 MVP의 필요보다 크므로 채택하지 않는다.

원장 전환 전에는 기존 포지션 편집을 유지하지만, 기초잔고 이관과 불변식 검증이 끝나 원장 쓰기를 활성화한 뒤에는 포지션 POST/PATCH/DELETE를 차단한다. 원장과 포지션을 동시에 독립적인 쓰기 원천으로 두면 복구 불가능한 불일치가 생기므로 점진적 이중 쓰기는 허용하지 않는다.

원장 거래가 한 건이라도 있는 포트폴리오는 삭제 요청을 `409 Conflict`로 거절한다. MVP에서는 거래 이력을 연쇄 삭제하거나 자동 보관하지 않으며, 포트폴리오 보관 기능은 별도 결정으로 남긴다.

## Consequences

- MVP는 USD 주식의 `OPENING_BALANCE`, `BUY`, `SELL`, `REVERSAL`만 지원한다. 현금, 배당, 분할, 환율, 세무 손익은 지원하지 않는다.
- 원장 쓰기 기능은 `marketboard.portfolio-ledger-writes-enabled=false`로 배포하고, 이관 건수·수량·평균단가 검증 후 `true`로 전환한다.
- 원장과 기존 투영의 정밀도는 수량 `DECIMAL(18,6)`, 단가·수수료 `DECIMAL(18,4)`로 맞추고 계산 중 추가 반올림은 하지 않는다.
- 포지션 투영은 원장에서 재생성할 수 있어야 하며 원장과 같은 트랜잭션에서 갱신한다.
- 과거 시점 거래 입력과 포트폴리오 보관은 후속 ADR 전까지 지원하지 않는다.
