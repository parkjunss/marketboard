# ADR 0003: 모의 주문 실행의 계산과 저장 경계

날짜: 2026-10-19

## 결정

Python `collector/app/execution.py`를 실행 상태·금액·수량의 유일한 계산 구현으로 사용한다. Spring `ExecutionService`만 실행 계좌 및 명령 원장을 쓴다. 사용자는 인증된 `/api/execution` API를 통해 자신의 실행만 읽거나 변경한다.

계좌 행을 `FOR UPDATE`로 잠그고 저장된 명령을 Python으로 재실행한 후 명령과 결과를 하나의 트랜잭션으로 기록한다. 요청 키는 실행 단위로 유일하며 같은 키의 다른 내용은 거절한다. 계산 서버가 실패하면 변경을 커밋하지 않는다. 생성은 사용자 행 잠금과 `(user_id, request_key)` 유일 제약으로 중복을 방지한다.

Python은 순수 계산이므로 DB 트랜잭션 중 계산 요청이 타임아웃되어도 외부 주문 부작용이 없다. 이 설계를 실제 증권사 주문 호출에 그대로 적용해서는 안 된다. 실제 연동에서는 영속 제출 의도와 독립 워커, 브로커 식별자 대사 경계를 별도 구현한다.

## 모의 거래소와 복구

`BUY`/`SELL`/`STRATEGY_BUY`는 주문 의도와 예약금을 저장한다. `DISPATCH`는 모의 브로커 접수를 기록한다. 체결·취소·거절 명령은 브로커 이벤트만 생성한다. `RECONCILE`이 수신 이벤트를 계좌에 반영한다. 접수·체결이 저장된 뒤 프로세스가 종료되어도 명령 원장에서 브로커 상태를 재구성할 수 있다.

`TIMEOUT`은 `UNKNOWN` 상태로 전환하며 자금을 해제하지 않는다. 동일 주문 ID의 재제출은 브로커 주문을 추가 생성하지 않는다. `REVERSE`는 브로커 이벤트를 역순으로 전달하며 누락 시퀀스를 버퍼링한다. `DUPLICATE`는 같은 이벤트를 두 번 전달하며 경제적 반영은 한 번만 한다.

다중 작업자의 도착 순서와 무관하게 모든 전략 결과가 같다는 의미가 아니다. 명령 순서는 DB에서 직렬화하며, 고정된 명령 기록과 버전의 재생이 결정론의 범위다. 동일 브로커 이벤트의 중복·역순 전달에 대해서는 경제적 상태 해시가 같아야 한다. 관측·장애 로그는 전달 경로에 따라 다를 수 있다.

## 가격·상태·리스크 계약

- 단일 SPY, 고정 모의 가격 USD 100. 실제 SPY 시세로 표시하지 않는다.
- `STRATEGY_BUY`는 SPY 보유 목표까지 서버가 수량을 계산한다. 수수료 차감 후 비중, 가용 현금, 최대 주문 금액을 함께 적용한다.
- 수량은 0.0001 단위, 금액 계산은 Decimal 및 소수점 8자리 반올림이다. 매수 수수료를 원가에 포함하고 매도 시 원가를 비례 차감한다.
- JSON 금액은 십진 문자열이다. DB의 현금·예약 현금·보유·예약 수량은 DECIMAL(28,8)로도 저장하고 CHECK 제약으로 보존 조건을 확인한다. Java와 브라우저는 재계산하지 않는다.
- 주문 상태: SUBMITTING → ACCEPTED → PARTIALLY_FILLED → FILLED/CANCELLED. 거절은 체결 전만 가능하다. UNKNOWN은 대사로 복구한다.
- 미종료 주문이 있으면 같은 실행에서 추가 주문을 막는다. 공매도·레버리지는 지원하지 않는다.
- 가격 신선도 장애는 `STALE_BUY`의 고정 시나리오다. 실제 시세 타임스탬프나 시계 동기화 검증은 아니다.
- 전량 청산 후 해당 실행에서 재진입을 영구 차단한다. 새 실행으로 별도 검증한다.
- STOP은 신규 주문 의도만 차단한다. 기존 주문 취소와 포지션 청산은 자동 수행하지 않는다.

## 범위와 비용

기존 ETF 모의 운용과 데이터가 분리된다. 신규 V40 테이블만 사용한다. 전체 명령 재생 비용을 제한하기 위해 실행당 최대 500개 명령이며 목록은 최근 30개 실행만 반환한다. 모의 검증을 위한 제한이며 실시간 대량 주문 엔진이나 운영 SLA를 주장하지 않는다.

수수료만 반영한 고정 가격 지정가형 모의 체결이다. 슬리피지·유동성·가격 개선·시장가·복수 자산·실제 거래소 취소 경쟁은 아직 범위에 없다. 운영 알림·자동 복구 워커·실시간 시세 연동은 후속 단계다.
