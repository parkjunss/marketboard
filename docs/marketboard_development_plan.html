Customizable Market Monitoring Platform

MarketBoard 개발 계획서

사용자가 주가지수, 관심 종목, 기술적 지표, 뉴스, 경제지표, 이상 신호 위젯을 자유롭게 배치하고 템플릿으로 저장·복사·공유할 수 있는 투자 관제 대시보드 플랫폼.

1. 프로젝트 개요

핵심 사용자 개인 투자자
핵심 가치 개인화·관제·탐지
개발 기간 6주 MVP 기준
운영 환경 라즈베리파이 홈서버

문제 정의

기존 금융 앱은 모든 사용자에게 비슷한 화면을 제공한다. 하지만 투자자마다 관심 시장, 종목, 투자 기간, 기술지표, 뉴스와 위험 관리 방식이 다르다. 사용자가 자신의 투자 방식에 맞는 모니터링 화면을 직접 구성할 수 있어야 한다.

서비스 한 줄 설명

주식시장 데이터를 위젯으로 조합해 자신만의 투자 관제 환경을 만드는 사용자 구성형 대시보드 플랫폼.

2. 목표와 차별점

개인화

자유로운 위젯 배치

사용자가 위젯을 추가하고 드래그·크기 조절하여 원하는 화면을 만든다.

진입 장벽 완화

기본 템플릿 제공

미국 시장, 국내 시장, 반도체, 장기 투자 등 목적별 템플릿을 제공한다.

관제

이상 신호 중심

시세만 보여주는 것이 아니라 거래량 급증, 변동성 확대, 공시 발생을 탐지한다.

플랫폼성

위젯 확장 구조

새 위젯을 추가할 때 기존 코드를 최소한으로 수정하도록 Provider 구조를 사용한다.

차별화 포인트

  • Grafana처럼 자유로운 레이아웃 편집
  • 시장별·전략별 기본 템플릿
  • 위젯 설정을 통한 종목·주기·조건 변경
  • 실시간 시세와 이상 신호 동시 모니터링
  • 개인 대시보드를 템플릿으로 저장·복사·공유
  • 추후 조건식 빌더와 템플릿 마켓으로 확장

라즈베리파이 저장 전략

데이터 저장 위치 보관 정책
실시간 틱Redis짧은 TTL
1분봉MySQL최근 기간 중심
일봉MySQL장기 보관
이상 이벤트MySQL영구 보관

모든 종목의 모든 틱을 라즈베리파이에 저장하지 않는다. 사용자가 구독한 종목과 필요한 시간 단위만 저장해야 디스크와 메모리를 감당할 수 있다.
